# 講義スライド依頼プロンプト（毎回コピーして使う）

［ ］の4項目だけを書き換えてください．任意項目は不要なら行ごと削除してかまいません．

---

```text
GitHub `YosukeSugiura/slide-master-ai`（main）の
design_system_general_final.md と content_visual_policy_final.md を読み，
それに従って次の講義の編集可能なPowerPointを作成してください．

講義名：［例：マルチメディア論］
回：第［N］回（［100］分）
内容資料：［添付ファイル名．構成案・素材・テンプレートなど］
厳守事項：［なければ「なし」］

（任意）枚数：［目安N枚／厳守N枚］
（任意）前回までの既習事項：［例：CNNは今回が初出］

進め方：
1. 作図の前に，全ページの「タイトル（主題・問い，1行）／主役と構図／Takeaway」を
   設計し，Takeawayをデザイン定義§3.3の基準で点検してから制作してください．
   内容資料にページ別のタイトルやTakeawayがあれば出発点にし，同じ基準で点検してください
   （文言の厳守を明示した行を除く）．
2. 内容資料の構成や文章は，厳守事項でない限り「目安」として扱い，
   分かりやすさのために言い換え・分割・統合してかまいません．
   数式・技術的事実・実測データ・承認済み図は変えないでください．
3. 完成したPPTXを全ページレンダリングし，policy §6 の不合格項目を直してから納品してください．
4. 最後に，主な構成変更・未提供の素材・未達事項・フォントの描画状況を短く報告してください．

定義ファイルを読めない場合は，作成を始める前にその旨を伝えてください．
```

---

## 書き方のヒント

- **厳守事項**には，その回だけの固定事項を書きます．共通の骨格（4:3，書体，章ラベル，フッターなし，右下の番号，Takeawayの書式）は定義ファイルにあるので書きません．
  - 例：「P.20のヒートマップは承認済み．再加工しない」「音A/Bは序盤で聞かせ，答えはスペクトルの段階で明かす」「Colab演習は最後にまとめる」
- **ページ別のタイトルとTakeawayを自分で決めたい場合**は，[`lecture_brief_template.md`](lecture_brief_template.md) の設計表を内容資料に含めてください．品質を最も安定させる方法です．
- 構成案の注意書き（「〜と断定しない」など）は，スライドに書く文ではなく**制作上の制約**として扱われます．図注として載せたい場合は，そう明記してください．
- GitHubを読めない環境では，2つの定義ファイルとこのプロンプトを添付し，1行目を「添付の定義ファイルを読み，」に変えてください．
