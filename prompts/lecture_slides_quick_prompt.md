# Claude / ChatGPT共通：講義スライド依頼プロンプト

以下の文章をコピーし，［ ］部分だけ必要に応じて変更してください．**空欄の任意項目は省略可能**です．

---

このGitHubリポジトリ `YosukeSugiura/slide-master-ai` の
`design_system_general_final.md` と `content_visual_policy_final.md` を読み，
添付した内容資料と図素材をもとに**［授業名］第［N］回**の編集可能なPowerPointを制作してください．

- **授業条件**：［授業時間・対象学年・必要な知識の前提］
- **狙い**：［学生に理解させたいことを1～3文］
- **入力**：［講義構成案，PPTXテンプレート，図PNG/CSV/WAV，必要な参考資料］
- **優先して見せたい内容**：［例：学習過程の実測図，実音声の聞き比べ，数式と実例の対応］
- **厳守する個別指定**：［例：4:3，指定ページの承認済み図，演習は最後］
- **自由に改善してよい点**：［未指定なら文章・図解・スライドの分割・統合・順序・主図レイアウト］
- **枚数**：［目安N枚，または厳守N枚と明示］

**制作方針**
1. 学習目標と説明の筋を守り，原稿は一字一句の写しではなく，講義として自然に再構成してください．
2. 書体（源真ゴシックPの指定），基本配色，既存テンプレートの固定要素は共通化しつつ，**全ページを同じレイアウトにしない**でください．Intro／Takeaway・カード・箇条書きは，理解を助ける場合だけ使ってください．
3. **数式，技術的事実，数値，実測結果，承認済み図の意味と内容は厳密**に扱ってください．模式図と実測図を区別し，未提供の実験値や画像を創作しないでください．画像のタイトル・重要ラベル・凡例は可能な限りPPTX側の編集可能要素にしてください．
4. ページタイトル，文章，図と数式の面積配分は各スライドの役割に合わせて選び，細かい座標や既定サイズに縛られて主図を小さくしないでください．
5. ページ数，見出し，説明文，図の構成が**目安**ならより良い案を提案・実施してよいですが，明示された**厳守条件は変更しない**でください．変更点を最終報告してください．
6. 過去のチャットや別の授業のスライドを暗黙に参照しないでください．今回参照を求めた資料だけを利用してください．矛盾・欠落が重大なときだけ質問してください．
7. 完成した編集可能PPTXを実際にレンダリングして全ページの文字切れ，図と説明の一致，フォント指定，実験データの忠実性を点検し，未達箇所を報告してください．

まず［**構成案を確認／そのまま制作**］の指示に従って進めてください．
