# P1 v3｜フィルタリングと特徴マップ S11–S22（20–44分）

全12枚×2分。手計算とプログラム実測を区別する。数値画像、座標、係数、矢印、応答値は分類Cで正確に描画。画像処理の境界条件は原則reflect、入力はfloat32に変換してから演算する。ただし手計算の単一3×3例は境界を含まない。

## S11｜なぜ画像にフィルタを適用するのか（2分）
**Intro：** 同じ画像でも、見たい構造に合わせて画素の計算方法を変えます。
**本文：**
- 平滑化：周辺の変動を抑える。
- 微分・勾配：明るさの変化を捉える。
- フィルタの係数によって反応する構造が変わる。
**主図：** 同一グレースケール画像を使用し、原画像／Gaussian平滑化／Sobel勾配強度を横並びに表示。Gaussianはσ=1.2など設定値を実記録。Sobelは元の輝度画像とは異なる測定量のため、単なる明るさ画像と同一の色スケールに見せない。別々のカラーバーを明記。
**Takeaway：** フィルタは画像中の特定の変動や構造を取り出す
**方式・素材：** C／D02。

## S12｜3×3カーネルが見る画素（2分）
**Intro：** フィルタは注目画素の周囲にある数値をまとめて処理します。
**本文：**
- 注目位置に3×3の局所領域を重ねる。
- 各位置に1つずつ係数が対応する。
- 出力を注目位置の値として記録する。
**主図：** 5×5入力配列の中心3×3を色枠で示し、右に係数3×3を完全な行列表示。入力画素と係数の対応を同じグリッド順で確認できるようにする。中心出力値のセルを1つだけ明示する。見た目だけで係数行列が画像上で逆順に見える設計は禁止。
**Takeaway：** フィルタは局所領域の画素と係数を対応させて計算する
**方式：** C。

## S13｜フィルタの積和を1画素だけ計算する（2分）
**Intro：** 画素とカーネル係数をそれぞれ掛け、その結果を足します。
**本文：**
- 画素値は各行が[0, 0, 100]の3行。
- 係数は各行が[-1, 0, 1]/3の3行。
- 出力は(100+100+100)/3=100。
**主図：** 左に3×3入力行列、中央に係数行列、右に9項の積和と結果100。対応セルを同色で結び、最終値100は一箇所だけ強調。正規化されたグレースケールではなく0〜255値の例とする。
**数式：** y(i,j)=Σ_m Σ_n K(m,n) x(i+m,j+n)。この表示は相互相関の定義であり、厳密な数学的畳み込みとは区別する。
**Takeaway：** 1画素のフィルタ出力は、近傍画素と係数の積和で決まる
**方式：** C（定量演算）。

## S14｜フィルタを画像全体へ適用する（2分）
**Intro：** 一か所の積和を、画像内の各位置で繰り返します。
**本文：**
- 同じカーネルを位置ごとに走査する。
- 位置ごとに1つの応答値を求める。
- 出力値の配列がフィルタ処理結果になる。
**主図：** 7×7入力を左、各位置での中心3×3領域を3コマ、右に出力配列。各コマの注目位置と出力位置を一致させる。stride=1、sameサイズの境界処理reflectと明記。出力サイズが一致する理由を曖昧にしない。
**Takeaway：** 同じ局所演算を画像全体で繰り返すと、出力画像が得られる
**方式：** C。

## S15｜相互相関と畳み込みは何が違うか（2分）
**Intro：** 「畳み込み」と呼ばれる処理には、係数の向きに注意が必要です。
**本文：**
- 相互相関：係数の並びをそのまま使う。
- 数学的畳み込み：係数を180度反転して使う。
- CNNの一般的な実装では相互相関が計算される。
**主図：** 非対称カーネルK=[[1,2,3],[4,5,6],[7,8,9]]と反転Krot=[[9,8,7],[6,5,4],[3,2,1]]を並べ、各演算の対応を明示。対称カーネルを例にしない。以後の説明は「相互相関としてのフィルタ演算」と記す。
**Takeaway：** CNNの「畳み込み」は、実装上は相互相関であることが多い
**方式：** C（係数方向の厳密比較）。

## S16｜平均フィルタ：周囲の値を平均する（2分）
**Intro：** 近傍画素を平均すると、急激な画素値の変化が弱まります。
**本文：**
- 3×3平均カーネルは全係数が1/9。
- 広い近傍では細かな模様が弱まりやすい。
- エッジもぼけるため、目的によっては不利になる。
**主図：** 同一実画像の原画像／3×3平均／7×7平均。3×3の全9セルに1/9を記載。7×7は全49係数が1/49とラベルで示す。境界reflect、0〜1へ正規化後に演算、出力を同じ0〜1表示範囲で比較。
**Takeaway：** 平均化は雑音を抑える一方、細部や境界も弱める
**方式・素材：** C／D02。

## S17｜Gaussianフィルタ：中心を重くする（2分）
**Intro：** Gaussian平滑化では、近い画素の寄与を大きくします。
**本文：**
- 中心近くの係数が大きく、離れると小さくなる。
- 同じ幅の一様平均とは係数の分布が異なる。
- 係数の和は1にそろえて明るさの平均レベルを保持する。
**主図：** 説明用の離散Gaussian近似K=(1/16)[[1,2,1],[2,4,2],[1,2,1]]と3×3平均行列を対比。対応する実験はこの厳密な3×3係数で処理し、同一入力・reflect境界・同一表示範囲で比べる。上記行列を無条件に「σ=1の正確な離散化」とは呼ばない。
**Takeaway：** Gaussian型平滑化は、近い画素ほど大きく重み付けする
**方式・素材：** C／D02。

## S18｜縦の境界に反応するSobelフィルタ（2分）
**Intro：** 左右方向の明るさが変わる場所では、縦方向の境界が現れます。
**本文：**
- x方向の変化をGxで求める。
- 左が暗く右が明るい境界では正の応答。
- 反対向きでは負の応答になりうる。
**主図：** 左暗・右明の画像とSobel Gx=[[-1,0,1],[-2,0,2],[-1,0,1]]。実測Gxの負・0・正をゼロ中心の発散色で表示。極端な明暗を示す例は元画像と勾配画像の正規化を混同しない。
**Takeaway：** 縦の境界は、左右の画素値の変化として検出できる
**方式・素材：** C／D02。

## S19｜横の境界に反応するSobelフィルタ（2分）
**Intro：** 上下方向の明るさが変わる場所では、横方向の境界が現れます。
**本文：**
- y方向の変化をGyで求める。
- 上が暗く下が明るい境界では正の応答。
- GxとGyは異なる変化方向を測る。
**主図：** 上暗・下明の画像とSobel Gy=[[-1,-2,-1],[0,0,0],[1,2,1]]。画像座標のy軸は下向きであることを明示。実測GyとGxの符号・表示スケールを区別する。
**Takeaway：** 横の境界は、上下の画素値の変化として検出できる
**方式・素材：** C／D02。

## S20｜Sobel勾配からエッジ強度を求める（2分）
**Intro：** 左右・上下の変化を合わせると、境界の強さを表せます。
**本文：**
- GxとGyは符号付きの変化量。
- エッジ強度M=√(Gx²+Gy²)は0以上。
- 強度だけでは変化の正負や全方向の情報は残らない。
**主図：** 同一入力のGx/Gy/Mを並べる。Gx・Gyには共通の対称表示範囲[-a,+a]、Mには[0,b]を明記し、対応位置を示す。aとbは実測の最大値等から定義して画像の注記に入れる。
**数式：** M(i,j)=√(Gx(i,j)²+Gy(i,j)²)。
**Takeaway：** 二方向の勾配を組み合わせると、輪郭の強さが分かる
**方式・素材：** C／D02。

## S21｜特徴マップとは何か（2分）
**Intro：** フィルタの応答を、入力の位置に対応させた配列が特徴マップです。
**本文：**
- 出力の各位置には局所パターンに対する応答が入る。
- 反応する方向や模様はフィルタ係数によって変わる。
- 一つの強い応答を「特定物体を認識した」とは解釈できない。
**主図：** 同じ輪郭線を入力と応答マップで1対1対応させる。特定の入力3×3領域を拡大し、その中心の積和を計算した出力セルへ結ぶ。複数位置の対応では、境界の隣接セルにも応答が出る可能性を明示。
**Takeaway：** 特徴マップは、画像のどこに特定の局所構造があるかを数値で示す
**方式・素材：** C／D02。

## S22｜複数フィルタから複数特徴マップへ（2分）
**Intro：** 一つの画像から、異なる性質を強調した出力を同時に作れます。
**本文：**
- 縦方向の境界：Gx。
- 横方向の境界：Gy。
- 局所的な平均レベル：平滑化結果。
**主図：** 入力画像1枚から3本の独立経路でGx/Gy/平均画像へ接続。Sobelの2応答には同一対称カラースケール、平均画像には0〜1強度スケールを表示。3つの出力を機械的に「RGB」と呼ばない。
**Takeaway：** 異なるフィルタを使うと、同じ画像から異なる特徴表現が得られる
**方式・素材：** C／D02。
