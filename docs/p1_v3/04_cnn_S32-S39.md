# P1 v3｜CNNと学習型画像Encoder S32–S39（63–79分）

全8枚×2分。第2回で学んだニューラルネットワークの損失とパラメータ更新を前提とし、CNNの詳細な逆伝播・Padding/Strideの一般式は扱わない。定量的な図・層形状・モデル実行結果を優先して分類Cとする。

## S32｜手設計したフィルタの限界（2分）
**Intro：** 一つのフィルタで、あらゆる形状や向きに反応できるわけではありません。
**本文：**
- Gxは主に左右の画素値変化に反応する。
- 対象を90°回転すると、反応する境界の向きも変わる。
- 多様な対象に適した係数を手作業で設計するのは難しい。
**主図：** 一つの人工図形（例：縦長の矩形）と、90°回転させた同じ図形を左右で対比。共通のSobel Gxに通し、応答マップを実計算する。必要ならGyも併記し、回転後のGx応答が「必ず消える」とは書かず「向き・空間位置が変わる」と表現。計算条件と表示尺度を固定。
**Takeaway：** 手設計フィルタの応答は、画像中の形状や向きに左右される
**方式・素材：** C（検証可能な画像変換と応答、D05補助）。

## S33｜CNN：フィルタの係数を学習する（2分）
**Intro：** CNNは、画像処理のフィルタ係数を学習パラメータとして扱います。
**本文：**
- 入力画素と重みの積和から特徴マップを作る。
- 教師あり分類なら、出力ラベルとの損失を使う。
- 損失を小さくするよう重みを更新する。
**主図：** 上段「入力画像＋係数K→相互相関→特徴マップ」、下段「特徴マップ→分類→予測→損失」。損失からKへ「学習時に更新」の戻り矢印。処理時の前向き矢印と学習時の更新矢印を種類で区別（色だけに依存しない）。CNNの重み更新が認識精度を必ず改善するとは断定しない。
**Takeaway：** CNNは目的の損失に合わせてフィルタの重みを学習する
**方式：** C（方向が検証できる接続図）。

## S34｜入力チャネルと出力チャネルの関係（2分）
**Intro：** 出力チャネル1枚を作るには、全入力チャネルの情報を組み合わせます。
**本文：**
- 入力がRGBなら入力チャネル数Cin=3。
- 3×3カーネルで2チャネルを出力する場合Cout=2。
- バイアスを除く重み数は2×3×3×3=54。
**主図：** RGB入力チャネル3枚を左に、出力チャネル2枚を右に配置。出力1枚には入力R/G/B各1枚の3×3係数が存在し、その3つの相互相関結果を足すことを具体的な線で表す。同じ構成がもう1つの出力にもある。重みテンソル形状[Cout,Cin,kH,kW]=(2,3,3,3)、バイアスは2個と明記。入力チャネルと出力チャネルを単純な一対一対応に描かない。
**式：** Y_o=b_o+Σ_{c=1}^{3} (K_{o,c} ⋆ X_c)。ここで⋆は相互相関。
**Takeaway：** CNNの各出力チャネルは、全入力チャネルの応答を足し合わせて作る
**方式：** C（精密構造図）。

## S35｜ReLUが加える非線形性（2分）
**Intro：** 畳み込み結果を非線形に変換すると、表現できる変換が広がります。
**本文：**
- ReLU(a)=max(0,a)。
- 負の値は0に、正の値はそのままにする。
- 畳み込みと活性化を組み合わせて層を構成する。
**主図：** 入力[-2,0,3]→ReLU→[0,0,3]の数値対応と折れ線グラフ。横軸a、縦軸ReLU(a)、負側が0で正側が傾き1。軸目盛・原点を一致させる。
**Takeaway：** ReLUは負の応答を0に変える非線形な活性化関数
**方式：** C（実数値関数）。

## S36｜Poolingで特徴を集約する（2分）
**Intro：** Poolingは局所領域の値をまとめ、空間方向のサイズを縮小します。
**本文：**
- 2×2 Max Poolingは4つの値から最大値を1つ残す。
- 出力の縦横サイズが縮小する。
- 最大値以外の値や位置の情報は失われうる。
**主図：** 2×2ブロック[[1,4],[2,3]]→最大値4を大きく表示。続けて4×4入力の4つの領域それぞれで最大値を採り2×2出力になる模式図。stride=2、重複なし。平均Poolと混同しない。
**Takeaway：** Max Poolingは局所的な最大応答を残し、空間情報を減らす
**方式：** C。

## S37｜CNNでは特徴マップを何層も変換する（2分）
**Intro：** 前の層の特徴マップが、次の層の入力になります。
**本文：**
- Convで複数チャネルを計算する。
- ReLUで非線形変換を行う。
- Poolingで空間サイズを小さくできる。
**主図：** 数値整合した教育用の例：8×8×1入力 → 3×3 Conv, padding=1, stride=1, 4 filters → 8×8×4 → ReLU → 8×8×4 → 2×2 Max Pool, stride=2 → 4×4×4 → 3×3 Conv, padding=1, stride=1, 8 filters → 4×4×8。各接続を片方向に示す。この図は形状説明用のモデルであり、S38の実モデルと一致しない場合は混同させない。
**Takeaway：** CNNは特徴マップを次の層へ渡し、段階的に変換する
**方式：** C（寸法一致が必須）。

## S38｜学習済みCNNの特徴マップを観察する（2分）
**Intro：** 学習済みモデルでは、同じ入力から層によって異なる応答が得られます。
**本文：**
- 共通のテスト画像を同じ前処理でモデルに入力する。
- 浅い層と深い層の特徴チャネルを観察する。
- 中間特徴の一つ一つに明確な意味があるとは限らない。
**主図：** sklearn digitsの8×8手書き数字画像を例に、実際に学習した小型CNNのConv1とConv2から複数チャネルを表示。モデルと層名、学習条件、入力画像ID、出力形状、チャンネルID、可視化の値範囲を脚注に記載。入力は画素/16に正規化した値0〜1。ランダム未学習モデルの出力を「学習済み」と称することは禁止。
**Takeaway：** CNNの特徴マップは、学習した重みと入力画像に応じて変化する
**方式・素材：** C／D05。

## S39｜CNN Encoderは何に使えるか（2分）
**Intro：** CNNで作った特徴表現は、後段の目的に応じて使い分けられます。
**本文：**
- 分類：特徴ベクトルからクラスのスコアを計算する。
- 検索：画像間の特徴ベクトルの距離を比較する。
- この用途ではDecoderを設ける必要はない。
**主図：** 「画像→CNN→特徴マップ→集約→特徴ベクトル」の後で「分類」と「類似検索」の2方向へ分岐。学習済み分類CNNから検索特徴として取り出す場合は、検索精度を検証しない限り「検索可能な表現例」とだけ記す。
**Takeaway：** CNNで学習した特徴は、分類や画像検索に利用できる
**方式：** C（単純で方向の正確な接続図）。
