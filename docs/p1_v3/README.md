## 表示設計と講師補足の区分
- スライドのタイトル・Intro・Takeawayは、原則それぞれ「タイトル」「Intro」「Takeaway」の文言を使用する。
- 各スライドの「本文」は表示用の要点候補。図内のラベルと完全に重複する情報は図へ統合可能だが、意味・前提・否定・正確な数値を落とさない。
- 「主図」「検査条件」「講師補足」の長い説明を、スライド本文に丸ごと表示しない。制作仕様またはノート欄として持ち、図と短いラベルへ適切に展開する。
- S26（5枚の4×4画像＋距離表）、S34（多入出力チャネル）、S38（CNN中間出力）は投影時の可読性をP2で重点検査し、16–18ptの本文・主要図ラベルを満たさない場合は、内容を欠落させず追加スライドへ分割する（現時点の49枚は内容設計上の番号）。
- 追加の同義補足文は原則置かない。例外的に必要な説明のみ18ptの薄灰背景を使用。

## 4:3 PPTXのデザイン（major固定規格）
- スライド：提供テンプレート優先、ない場合4:3。通常背景白 #FFFFFF。ブランド主色 #41419E、本文 #30323B、補助 #555B6A。
- 編集可能な全テキスト：源真ゴシックP。タイトル32pt Heavy、Intro22pt Medium、小見出し22pt Bold、本文16–18pt Medium、図中文字16–20pt、注釈12–14pt。
- Takeaway：白地、インディゴ1–1.5pt直線枠、24pt Bold、中央揃え。表紙には機械的に設けない。
- スライド全体を画像化しない。タイトル・Intro・本文・専門用語・数値・図軸・表・Takeawayは原則としてPPTX上で編集可能にする。
- テンプレートにロゴ・点線・ページ番号が存在する場合、想像で二重作成・移動しない。画像素材の画角と原寸縦横比を守る。

## 図のA/B/C判定
major/content_visual_policy_final.mdの分類は領域ごとの説明目的と正確性で判断する。今回は画素行列・係数・数式・符号付き応答・実験結果・重みテンソル・精密接続・表が主図なので、**P1で仕様化した49枚の主領域は現時点ではC**としている。これは制作を簡略化するための一括判断ではなく、各スライドでCが必要な理由を主図仕様に明示したものである。
- S02/S03/S04/S33/S39/S41/S44などの単純接続図は、矢印の厳密な方向・情報の依存先が主眼のためC。
- S32は実際の図形変換とGx/Gy数値比較なのでC。
- A/Bが必要な「概念を理解させる一体絵／具体的行動の内部場面」は現時点で要求していない。P2でそれが不可欠と判明した領域は内容を保存したうえでA/Bに再分類し、独立素材の意味契約と10項目の事前ゲートを作る。A/Bの主図を箱・矢印の寄せ集めで代替しない。
