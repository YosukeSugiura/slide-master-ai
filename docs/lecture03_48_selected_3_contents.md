- **本ファイル単独に3枚分のタイトル、Intro、本文・図中ラベル、Takeaway、表データ、固有の制作方針を収録**する。元48枚分のファイルを別途取得できなくても、この3枚の内容定義として利用できる。
- PPTX制作時の参照先：[`design_system_general_final.md`](../design_system_general_final.md) **v2.0**（配色、フォント、余白、4:3、Takeaway）と、[`content_visual_policy_final.md`](../content_visual_policy_final.md) **v2.3**（分類A/B/C、段階的な画像生成、検証）。本ファイルが指定する講義内容・意味関係を最優先する。
- スライド11の**プロダクトオーナー**専用画像生成指示の既存案は[`S11_B_PRODUCT_OWNER_v1.3.md`](prompts/S11_B_PRODUCT_OWNER_v1.3.md)。このファイルはv2.2時点の版を履歴として維持し、**現行v2.3の事前検査とユーザーレビューを行ったうえで確定・実行**する。同スライド内の**プロダクトオーナーの内部イラスト1点に限って使用**し、スクラムマスター、開発者、スライド17のMLOps主図へ流用しない。
- 制作順は**11 → 17 → 35**。分類は順に**B（3比較対象ごとに内部イラスト）／A（MLOpsの統合主図）／C（編集可能な入力チェック表）**。文字・枠・説明・TakeawayはPPTXの編集可能要素とする。
- 原稿の語句、数字、工程の方向、用語、比較対象、表の列・行、句読点（`，`・`．`）は**省略・言い換え・創作しない**。本ファイル中の「参考位置」は元原稿を確認するための補助情報であり、座標の流用や固定配置を命じるものではない。
- 画像生成に際しては、最初に**完成品がスライド全体ではなく、後からPPTXへ挿入する独立画像素材1点**であることを宣言し、各素材の固有の内容・禁止事項を指示する。単に「文字のない図」と指定して済ませない。
- **実行は段階的に分離する**：素材ごとのプロンプト案作成・事前検査 → ユーザーが全文を確認・修正して実行承認 → 新規の画像専用チャットで確定した画像プロンプトだけを投入 → 素材検証 → PPTX統合。実行手順は[`IMAGE_GENERATION_STAGED_WORKFLOW_v1.md`](IMAGE_GENERATION_STAGED_WORKFLOW_v1.md)に従う。Image APIは必要時の別途承認を要する選択肢とする。
- 吹き出し・行動ラベル等をPPTXで追加して、画像に描かれている内容を明瞭にしてよい。ただし**画像に欠けている必須行動を文章だけで補って画像単体を合格扱いしない**。
- 別スライド、過去の生成画像、既存スライド、旧デザイン、旧プロンプトを制作の下敷きにしない。
