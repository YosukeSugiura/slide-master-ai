# 第3回 v5：境界処理の追加と実験図の拡大（2026-10-15）

## ユーザー指定による改訂
- 元のv4 49枚の「フィルタを画像全体へ適用する」の**直後**に、ゼロパディングとリフレクトパディングを比較するスライドを追加（v5のS15）。
- 3×3画像（1〜9）に対して5×5の拡張を計算し、3×3平均フィルタの左上出力はゼロパディングで12/9=1.3333、SciPy ndimage reflectで21/9=2.3333であることを実計算で確認。
- reflectの定義は端画素を含む鏡映（SciPy ndimage.mode='reflect'）。NumPy pad(mode='reflect')とは端の扱いが異なる点を明記。
- 画像処理・RGB分解・Sobel・特徴マップ・ブロック平均・AE復元などの図を優先して拡大。主に画像3〜4点比較のページで、元の図の表示幅に対して約1.65〜1.77倍。
- 左側の冗長な箇条書きをコンパクトな図下注記へ移し、主図を視覚的な中心にした。
- 「元画像と復元画像」および「差分画像とMSE」を2枚へ分割。
- CNNのConv1浅層特徴とConv2深層特徴を2枚へ分割。
- 内容の薄いスライドの統合は主図を小さくする可能性があるため、今回は実施しない。最終枚数52枚（49+1+2）。
