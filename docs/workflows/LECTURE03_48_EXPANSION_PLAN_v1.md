# S3_EXTENSION_PLAN — 元48枚版への制作計画

開始条件: GitHub minor のSTATE.mdが S3_EXTENSION_PLAN / READY であり、ユーザーが次と入力する。

1. GitHubにある元48枚版 lecture03_48_slide_contents.md を取得する。未取得の資料を推測して補完しない。
2. 各スライドの目的・主図分類A/B/Cと、必要な独立画像の点数・素材IDを一覧化する。
3. 今回の試作を踏まえ、**PPTX骨組み先行→挿入枠の計測→独立画像生成→検証→PPTX挿入→実レンダリング**を既定の制作順とする。
4. タイトル・Intro・Takeaway・表などの正確な情報は編集可能テキストで保持。役割説明は意味を保った短い体言止め・箇条書き。重複する補足文は省略。
5. 画像生成の失敗率は実測されていないため推測を成功率として報告しない。通常生成で最大3試行とし、外部API課金には個別承認が必要。
6. 源真ゴシックPの実描画未確認、統合主図の意味検証、48枚全体のQA・納品工程を計画書に明示。
7. 計画書・結果をGitHubに記録し、STATEを更新。実際に48枚全体を生成するのは後続工程で、同じチャットの次の指示を待つ。

旧A/B/C制作順序比較のE03は保留状態を維持する。
