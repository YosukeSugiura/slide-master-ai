## 次の「次」：S17_IMG

**生成する完成品は独立したMLOps循環主図の画像1点のみ。**

この工程で利用するのは、PPTXに確定済みの画像の挿入領域（約1.84:1）と次の**主図の意味契約だけ**。**前の失敗したスライド画像、スライドタイトル、Intro、Takeaway、比較実験A/B/C、PPTX全体のスクリーンショットを画像生成指示に混ぜない**。

- データ収集 → 前処理 → 学習 → 評価 → 配備 → 監視。
- 監視結果に応じた再学習・モデル更新から再配備へ戻る明確な経路。順序の省略、誤接続、矢印逆転は不可。
- 画像内部にタイトル・長文・日本語ラベル・疑似テキストを作らず、**主体・処理の違い・矢印の循環を一体化した2Dフラットの視覚表現**とする。
- PPTX用説明文やTakeawayは生成対象外。スライド全体画像、カードの羅列だけ、比較ポスターは不合格。
- 透明背景を優先、インディゴ系、画角は横長。素材の上下左右に適切な余白を持たせて切断しない。
- 画像を実際に生成後、元原稿との意味照合と画像単体の5軸評価、文字混入・範囲違反・背景・縮小表示を検証。内部実効プロンプトが観測不能なら未確認と記録。
- 重大な違反でFAILなら合格とせずログ保存し、同一生成器で無制限に反復しない。

**工程がPASSの場合のみ** `current_step=S17_INSERT` へ進める。未達なら `BLOCKED`、次工程に進まない。
