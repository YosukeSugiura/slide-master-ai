# 第3回 P1 詳細案 S32–S49
形式：番号｜主題｜図で示すべき意味。CNNは学習済み重み、Autoencoderは実測の再構成結果を使用。

## CNN：学習される画像Encoder（63–79分）
S32｜手設計特徴の限界｜多様な撮影条件・形状・明るさに対し固定的な特徴だけでは不十分な例。
S33｜CNNの畳み込み層｜画像の画素値と学習される係数の積和から特徴マップを得る。
S34｜入力と出力のチャネル｜Cin=3、Cout=2、3×3カーネルの重み形状(2,3,3,3)と積和対応。バイアス別。
S35｜ReLU｜負値を0へ変える非線形演算、[-2,0,3]→[0,0,3]。
S36｜Pooling｜2×2最大値poolingの数値計算、位置情報の減少。
S37｜CNNの層の重なり｜Conv→ReLU→Pool→Conv、各段階の形状が整合する図。
S38｜学習済みCNNの特徴マップ｜モデル名、重み、入力、前処理、層名、チャネル、濃度尺度を明記した実測出力。
S39｜画像Encoderの用途｜CNN→集約→特徴ベクトル→分類／類似画像検索。Decoderは必須ではない。

## Autoencoder：再構成する画像表現（79–96分）
S40｜認識と再構成の違い｜正解ラベルと復元画像という目的・損失の違い。
S41｜Autoencoderの全体｜x→Encoder→z→Decoder→xhat。元画像との対応。
S42｜潜在表現｜64画素からz=2/8/32などの変換。次元数はビット数とは異なる。
S43｜MSEの計算｜同じ位置の画素差を二乗平均する2×2の数値例。
S44｜AEの学習｜入力→復元→誤差→パラメータ更新。第2回と接続。
S45｜同じ入力で比較｜held-out画像を固定しz=2,8,32の実測復元を並べる。
S46｜何が失われたか｜入力／復元／絶対誤差画像の位置を正確に対応。
S47｜テストMSE｜評価画像・学習条件・seed・モデル構造を明記した実測グラフ。改善を一般定理としない。

## まとめ（96–100分）
S48｜認識用と再構成用Encoder｜目的、保持表現、出力、損失、Decoderの要否の比較表。
S49｜理解確認と第4回｜「特徴マップと特徴ベクトルの違い」「平均化は可逆か」「AEは何を学習するか」を確認し、音響特徴量と音声Encoderへ接続。

## 実験と精度の注意
- D05学習済みCNNの同一入力に対する浅層／深層の応答を使用する。ランダム初期化モデルの特徴マップは学習済みと称さない。
- D06Autoencoderの潜在2/8/32の比較では評価集合・学習条件を固定し、同じテスト画像を表示する。
- 潜在次元が増加すると必ずテストMSEが下がるとは断定しない。
- CNNの深層マップに人間が理解する一つの意味が付くと断定しない。
