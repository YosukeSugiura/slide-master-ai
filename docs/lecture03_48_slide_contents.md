# スライド内容指定ファイル：情報システム論 第3回「ソフトウェア開発」（48枚版）

## 0. 対象原稿と適用範囲

- **対象は `情報システム論_第3回_ソフトウェア開発.pptx` の全48枚（4:3、2025年度表記）に限定**する。53枚版および53枚版の修正原稿は参照しない。
- 本ファイルは**各スライドの内容、論理構成、図解の意味、個別の配置の指定**であり、汎用デザインルールは別添の `design_system_general.md` を適用する。
- **全48枚の順番・タイトル・本文・事例・数値・用語・表の列行・設問と回答・プロンプト本文・Takeawayを保持**する。勝手な省略、補完、再編、再解釈、最新資料への差し替えは禁止。
- 表紙には原稿どおり**「2025年度」「全48枚」**と表記する。2026年度へ更新する指示はないので変更しない。
- 文章の `，` と `．`、用語の全角半角、数値、固有名称は原則そのまま用いる。PPTXにある箇条書き用のゼロ幅制御文字のみ可視文字ではないため省いた。
- 「参考位置」は元PPTXのテキストボックスの領域をスライド幅・高さに対する百分率で示す**再現上の補助情報**であり、絶対座標で固定する指定ではない。共通デザインに適合させつつ、左右・上下・要素間の順序を保持する。参考位置の数値を印字しない。
- 「図解・レイアウトの指示」にある図は編集可能なPowerPoint図形・文字として作成する。矢印の方向、階層、対応、反復、入力部品、意味別の色を保つ。
- 元PPTXの図中には装飾用の画像線があるが、意味上の必須情報は以下の文字と図解説明に列記する。写真やロゴを独自に創作して追加しない。
- **テンプレート側にロゴ、タイトル下の点線、ページ番号等がある場合は、新規に生成せず既存要素を使用**する。テンプレート未提供時はそれらを推測して描き足さない。
- **元の48枚版と矛盾する修正を自動で行わない**。数学的・技術的な整合性に確認を要する表現があっても、原文を保持し別途確認事項として報告する。
- 表紙には通常のTakeawayを付けない。その他のスライドは「キーメッセージ（Takeaway）」に記した文言を下部に配置する。
- 各章の「内容・図中ラベル」は要素ごとの原文であり、生成用メタ情報（ブロック番号、参考位置、注釈）はスライドに印字しない。
