# slide-master-ai — 講義スライド生成の共通ルール

明治大学の講義を中心に，ChatGPT／Claude for PowerPoint等へ**短いプロンプトで再利用できる**設計ルールをまとめたリポジトリです．

## 最初に読むファイル

1. [design_system_general_final.md](design_system_general_final.md) — フォント，配色，文字階層，編集可能性などの共通デザイン．
2. [content_visual_policy_final.md](content_visual_policy_final.md) — 学習内容に応じた図解選択，実測データの扱い，検査方法．
3. [prompts/lecture_slides_quick_prompt.md](prompts/lecture_slides_quick_prompt.md) — **毎回の依頼にそのまま使う短い指示文**．
4. [prompts/lecture_brief_template.md](prompts/lecture_brief_template.md) — 必要に応じて追加する講義個別の条件．

## 最重要：何を厳密に守るか

| 厳密に守る | 内容に応じて柔軟に変えてよい |
|---|---|
| 数式・技術的事実・数値・重要な関係・学習目標 | 言い回し・説明量・具体例・スライド内の配置 |
| 承認済みの実測図と原本データ，明示的な禁止事項 | 図解の種類・画像の比率・本文と図の面積配分 |
| 指定フォント・テンプレート・基本色のデザイン言語 | Intro／Takeawayの使用，ページ分割・統合，枚数の目安 |

- **「構成案」「目安」「例示」は原則，変更可能**．「厳守」「固定」と指定された要素は変更しない．
- 4:3はテンプレート未指定時の既定値．源真ゴシックPのPPTX内指定・基本インディゴ系は共通の原則．実環境で描画できない場合は報告する．
- どのページにも同じ「タイトル→導入→図→Takeaway」を機械的に押し付けない．図が主役，問題提示，数式中心，演習などで構図を変える．
- 実測図・実測値の改変や「期待した結果」を実験結果と偽ることは禁止．図は独立したPNG/SVG等を配置し，タイトルや注釈は原則PPTX内で編集可能にする．
- **過去のチャットや過去版を暗黙に流用しない**．ユーザーが今回の入力として明示した講義PPTX・素材は参照してよい．
- 既存スライドへの適用時は，元の意味を保持しつつ，構成や文章を改善してよい．実測データに矛盾を発見した場合は変更せず報告する．

## 毎回の依頼（最短）

```text
このリポジトリの2つの定義ファイルと prompts/lecture_slides_quick_prompt.md に従って，
添付の授業計画と素材から［授業名・第N回］の編集可能なPPTXを作成してください．
内容は学習目標と事実を守りながら分かりやすく再構成し，ページ構成は目安として扱ってください．
厳守したい個別事項：［なければ「なし」］
```

GitHub上のファイルがClaude側で読めない場合は，**最初の2定義ファイル＋quick_prompt**を添付し，同じ依頼を行ってください．

## 推奨制作フロー

1. 入力を確認し，足りない必須情報だけ質問する．
2. 先に講義のストーリーとページ配分を示す（ユーザーが直接制作を求めた場合は作成へ進む）．
3. 図・本文・数式を，意味上必要な精度で作成．
4. PPTXそのものをレンダリングして見切れ，重なり，誤字，データ差し替え，画像の不一致を検査．
5. 編集可能なPPTX，検査結果，未完了事項，重要な構成変更点を納品．

詳しい指定例と必須／推奨／自由の切り分けは上記テンプレートを参照してください．
